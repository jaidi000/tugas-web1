Alur & Timeline Kegiatan Belajar Mandiri

Berikut adalah urutan tahapan belajar dan pengerjaan proyek yang rutin saya jalankan:

  1. Minggu 1-2: Perancangan & Analisis Kebutuhan
    • Membuat wireframe antarmuka pengguna (UI/UX)
    • Menyusun skema basis data dan relasi antar tabel
  2. Minggu 3-4: Pengodean Tampilan (Frontend)
    • Menulis struktur dokumen HTML5
    • Menerapkan gaya tampilan responsif dengan CSS
  3. Minggu 5-6: Pengembangan Logika (Backend) & Pengujian
    • Membuat API dan integrasi basis data
    • Pengujian fungsi dan perbaikan bug

Glosarium Istilah Web Development

Frontend Development
Bagian dari pengembangan web yang berfokus pada tampilan antarmuka dan interaksi langsung dengan pengguna di peramban (browser).
Backend Development
Bagian dari pengembangan web yang menangani logika bisnis, pemrosesan server, autentikasi, dan pengelolaan basis data.
REST API
Antarmuka pemrograman aplikasi yang memungkinkan dua sistem atau aplikasi saling berkomunikasi dan bertukar data melalui protokol HTTP.
